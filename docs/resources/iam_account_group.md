# radosgw_iam_account_group

Manages an IAM group within a RadosGW account (IAM `CreateGroup`). Groups collect users so policies can be granted to all members at once (see `radosgw_iam_account_group_policy`, `radosgw_iam_account_group_policy_attachment`, and `radosgw_iam_account_group_membership`). Manage it with account-root credentials — no admin capability required.

## Example Usage

```terraform
resource "radosgw_iam_account_group" "engineering" {
  provider = radosgw.account_root
  name     = "engineering"
  path     = "/teams/"
}
```

## Argument Reference

The following arguments are supported:


* `name` - (Required) The name of the group. Can be renamed in place.


* `path` - (Optional) The path for the group (an IAM path, which must begin and end with `/`). Defaults to `/`.




## Attributes Reference

The following attributes are exported:

* `arn` - The Amazon Resource Name (ARN) that identifies the group.
* `unique_id` - The stable unique identifier assigned to the group by RadosGW.
* `name` - See Argument Reference above.
* `path` - See Argument Reference above.
## Import

Import is supported using the following syntax:

```shell
# Import a group by name
```
