# radosgw_iam_account_user_policy_attachment

Attaches a managed policy (e.g. `arn:aws:iam::aws:policy/AmazonS3ReadOnlyAccess`) to an account IAM user (IAM `AttachUserPolicy`). Like `aws_iam_user_policy_attachment`, it manages a single attachment, so several can target the same user without conflict. Manage it with account-root credentials. For inline policies, use `radosgw_iam_account_user_policy`.

## Example Usage

```terraform
# Attach an AWS-managed policy to an account user.
resource "radosgw_iam_account_user_policy_attachment" "read_only" {
  provider   = radosgw.account_root
  user       = radosgw_iam_account_user.developer.name
  policy_arn = "arn:aws:iam::aws:policy/AmazonS3ReadOnlyAccess"
}
```

## Argument Reference

The following arguments are supported:


* `policy_arn` - (Required) The ARN of a built-in managed policy to attach. RadosGW does not support custom managed policies (there is no `CreatePolicy`), so this must be one of the six predefined managed policies: `arn:aws:iam::aws:policy/AmazonS3FullAccess`, `.../AmazonS3ReadOnlyAccess`, `.../AmazonSNSFullAccess`, `.../AmazonSNSReadOnlyAccess`, `.../IAMFullAccess`, or `.../IAMReadOnlyAccess`. Any other ARN returns `NoSuchEntity`. For custom permissions, use an inline policy (`radosgw_iam_account_user_policy`) instead.
* `user` - (Required) The name of the IAM user to attach the policy to.




## Attributes Reference

The following attributes are exported:

* `id` - The identifier of the attachment. Format: `user/policy_arn`.
* `policy_arn` - See Argument Reference above.
* `user` - See Argument Reference above.
