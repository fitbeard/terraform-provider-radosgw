# radosgw_s3_bucket_public_access_block

Manages the S3 Public Access Block configuration for a bucket in RadosGW, via the standard S3 `PutPublicAccessBlock` API. This is the RadosGW equivalent of `aws_s3_bucket_public_access_block` and lets you block or ignore public access granted via ACLs and bucket policies.

### Ceph version support

Support is **per-setting** and depends on the provider's `ceph_version`:

| Setting | Minimum Ceph release |
| --- | --- |
| `block_public_acls` | Squid (19) or earlier |
| `ignore_public_acls` | Squid (19) or earlier |
| `block_public_policy` | Squid (19) or earlier |
| `restrict_public_buckets` | **Tentacle (20)** — added in 20.2.0 |

`restrict_public_buckets = true` is rejected at plan time when `ceph_version` is older than Tentacle, where RadosGW does not implement the property and would silently fail to enforce it. The other three settings work on all supported releases.

~> **Verified on Ceph 21.2.0 (Umbrella):** all four settings round-trip and are enforced (`block_public_acls` rejects public-ACL `PutObject`; `ignore_public_acls` makes a public object's anonymous read return 403; `block_public_policy` rejects a public bucket policy). On **Tentacle before 20.2.3**, `block_public_acls` had a bug that rejected ordinary (non-public) uploads — upgrade to 20.2.3+ before enabling it.

~> **Note:** A bucket has a single public-access-block configuration. Declaring multiple `radosgw_s3_bucket_public_access_block` resources for the same bucket will cause them to overwrite each other.

## Example Usage

```terraform
# Lock down a bucket: block and ignore all public access.
resource "radosgw_s3_bucket" "example" {
  bucket = "my-private-bucket"
}

resource "radosgw_s3_bucket_public_access_block" "example" {
  bucket = radosgw_s3_bucket.example.bucket

  block_public_acls   = true
  block_public_policy = true
  ignore_public_acls  = true

  # restrict_public_buckets requires Ceph 20 (Tentacle) or higher.
  restrict_public_buckets = true
}
```

## Argument Reference

The following arguments are supported:


* `bucket` - (Required) The name of the bucket.


* `block_public_acls` - (Optional) Whether RadosGW should block public ACLs for this bucket. When `true`, `PutObject`/`PutBucketAcl` requests that specify a public ACL are rejected. Defaults to `false`.
* `block_public_policy` - (Optional) Whether RadosGW should block public bucket policies for this bucket. When `true`, `PutBucketPolicy` requests that grant public access are rejected. Defaults to `false`.
* `ignore_public_acls` - (Optional) Whether RadosGW should ignore public ACLs for this bucket. When `true`, any existing public ACLs on the bucket and its objects are ignored (access is treated as private). Defaults to `false`.
* `restrict_public_buckets` - (Optional) Whether RadosGW should restrict public bucket policies for this bucket. When `true`, access to a bucket with a public policy is restricted to authorized users within the bucket owner's account. Defaults to `false`. **Requires Ceph 20 (Tentacle) or higher** — this property was added in Tentacle 20.2.0 and setting it to `true` is rejected at plan time on older releases.
* `skip_destroy` - (Optional) When `true`, the public-access-block configuration is left in place on the bucket when this resource is destroyed (instead of being removed). Defaults to `false`.
