# radosgw_iam_account_group_membership

Manages the membership of a RadosGW account IAM group (IAM `AddUserToGroup` / `RemoveUserFromGroup`). Manage it with account-root credentials.

~> **Exclusive membership:** this resource manages the group's **entire** member list, like `aws_iam_group_membership`. Any user added to the group outside Terraform is removed on the next apply. To manage a single user's membership non-exclusively, add the user via a separate mechanism.

## Example Usage

```terraform
# Manages the group's FULL member set (exclusive).
resource "radosgw_iam_account_group_membership" "engineering" {
  provider = radosgw.account_root
  group    = radosgw_iam_account_group.engineering.name
  users = [
    radosgw_iam_account_user.developer.name,
    radosgw_iam_account_user.analyst.name,
  ]
}
```
