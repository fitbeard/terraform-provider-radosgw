# radosgw_iam_account_user_policy

Manages an **inline** IAM policy for a user within a RadosGW account (IAM `PutUserPolicy`). This is how you grant permissions to a `radosgw_iam_account_user`. Manage it with account-root credentials (no admin capability required). For AWS-managed policies, use `radosgw_iam_account_user_policy_attachment` instead.

## Example Usage

```terraform
data "radosgw_iam_policy_document" "s3_read" {
  statement {
    effect    = "Allow"
    actions   = ["s3:ListBucket", "s3:GetObject"]
    resources = ["*"]
  }
}

# Grant an account user permissions with an inline policy.
resource "radosgw_iam_account_user_policy" "read" {
  provider = radosgw.account_root
  user     = radosgw_iam_account_user.developer.name
  name     = "s3-read"
  policy   = data.radosgw_iam_policy_document.s3_read.json
}
```

## Argument Reference

The following arguments are supported:


* `name` - (Required) The name of the policy. Must be unique within the user.
* `policy` - (Required) The policy document (in JSON format). Use `jsonencode()` or the `radosgw_iam_policy_document` data source to generate this.
* `user` - (Required) The name of the IAM user to attach the inline policy to.




## Attributes Reference

The following attributes are exported:

* `id` - The unique identifier for this policy. Format: `user:policy_name`.
* `name` - See Argument Reference above.
* `policy` - See Argument Reference above.
* `user` - See Argument Reference above.
## Import

Import is supported using the following syntax:

```shell
# Import an inline user policy using "user:policy_name"
terraform import radosgw_iam_account_user_policy.read "developer:s3-read"
```
