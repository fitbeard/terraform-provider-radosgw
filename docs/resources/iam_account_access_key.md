# radosgw_iam_account_access_key

Manages an access key for a user **within a RadosGW account**, using the S3/IAM API (`CreateAccessKey`) rather than the Admin Ops API.

Use this together with `radosgw_iam_account_user`: it lets an **account root** — or a member holding an IAM policy granting `iam:CreateAccessKey` (e.g. for self-service keys) — issue S3 credentials **without any admin capabilities**. For admin-managed RGW users (with Swift keys, custom key values, etc.) use `radosgw_iam_access_key` instead.

~> **Note:** Unlike `radosgw_iam_access_key`, the key pair is **generated by RadosGW** — you cannot supply your own `access_key`/`secret_key`. The `secret_key` is only returned when the key is created; it cannot be recovered later (including on import).

## Example Usage

```terraform
resource "radosgw_iam_account_user" "developer" {
  provider = radosgw.account_root
  name     = "developer"
}

# RadosGW generates the key pair; the secret is only available at create time.
resource "radosgw_iam_account_access_key" "developer" {
  provider = radosgw.account_root
  user     = radosgw_iam_account_user.developer.name
  status   = "active"
}

output "developer_access_key_id" {
  value = radosgw_iam_account_access_key.developer.access_key
}

output "developer_secret" {
  value     = radosgw_iam_account_access_key.developer.secret_key
  sensitive = true
}
```

## Argument Reference

The following arguments are supported:


* `user` - (Required) The IAM user (name) that the access key belongs to.


* `status` - (Optional) The status of the access key: `active` (default) or `inactive`.




## Attributes Reference

The following attributes are exported:

* `access_key` - The generated access key ID.
* `create_date` - The date and time the access key was created, in RFC 3339 format.
* `secret_key` - The generated secret access key. Only available at creation time; null on import.
* `user` - See Argument Reference above.
* `status` - See Argument Reference above.
## Import

Import is supported using the following syntax:

```shell
# Import an account IAM access key using "user:access_key_id".
# The secret cannot be recovered on import.
terraform import radosgw_iam_account_access_key.developer "developer:AKIAEXAMPLE0001"
```
