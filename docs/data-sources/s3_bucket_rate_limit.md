# radosgw_s3_bucket_rate_limit

Retrieves the rate limit configured for an S3 bucket in RadosGW via the Admin Ops API (`ratelimit-scope=bucket`).

~> **Admin capability required.** Reading a bucket rate limit requires the Admin Ops `ratelimit` capability (`ratelimit=read`). A user without it receives `AccessDenied`.

~> **Ceph version:** `max_list_ops` and `max_delete_ops` were added in Ceph 21 and are not exposed yet (the latest stable release is Tentacle, 20).

## Example Usage

```terraform
# Look up the rate limit configured for an existing bucket
data "radosgw_s3_bucket_rate_limit" "example" {
  bucket = "my-rate-limited-bucket"
}

output "bucket_rate_limit" {
  description = "Rate limit settings for the bucket"
  value = {
    enabled         = data.radosgw_s3_bucket_rate_limit.example.enabled
    max_read_ops    = data.radosgw_s3_bucket_rate_limit.example.max_read_ops
    max_write_ops   = data.radosgw_s3_bucket_rate_limit.example.max_write_ops
    max_read_bytes  = data.radosgw_s3_bucket_rate_limit.example.max_read_bytes
    max_write_bytes = data.radosgw_s3_bucket_rate_limit.example.max_write_bytes
  }
}
```

## Argument Reference

The following arguments are supported:


* `bucket` - (Required) The name of the bucket to look up.


* `tenant` - (Optional) The tenant that owns the bucket. Leave unset for a bucket in the default namespace. When set, the bucket is addressed as `tenant/bucket`.



## Attributes Reference

The following attributes are exported:

* `enabled` - Whether the rate limit is enabled for the bucket.
* `max_read_bytes` - Maximum read bytes per minute. `0` means the limit is disabled.
* `max_read_ops` - Maximum read operations per minute. `0` means the limit is disabled.
* `max_write_bytes` - Maximum write bytes per minute. `0` means the limit is disabled.
* `max_write_ops` - Maximum write operations per minute. `0` means the limit is disabled.
* `bucket` - See Argument Reference above.
* `tenant` - See Argument Reference above.
