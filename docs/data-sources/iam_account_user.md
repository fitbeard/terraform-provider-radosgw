# radosgw_iam_account_user

Looks up an IAM user within a RadosGW account (via the IAM `GetUser` API). Use with account (or `iam:GetUser`-granted) credentials. See `radosgw_iam_account_user`.

## Example Usage

```terraform
data "radosgw_iam_account_user" "developer" {
  provider = radosgw.account_root
  name     = "developer"
}

output "developer_arn" {
  value = data.radosgw_iam_account_user.developer.arn
}
```

## Argument Reference

The following arguments are supported:


* `name` - (Required) The name of the IAM user to look up.



## Attributes Reference

The following attributes are exported:

* `arn` - The user's ARN.
* `create_date` - The date and time the user was created, in RFC 3339 format.
* `path` - The user's IAM path.
* `unique_id` - The user's stable unique identifier.
* `name` - See Argument Reference above.
