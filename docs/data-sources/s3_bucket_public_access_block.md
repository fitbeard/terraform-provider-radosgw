# radosgw_s3_bucket_public_access_block

Reads the S3 Public Access Block configuration of a bucket in RadosGW, via the standard S3 `GetPublicAccessBlock` API.

~> **Note:** When a bucket has no public-access-block configuration, all four settings are reported as `false` — the effective state, in which nothing is blocked. See [`radosgw_s3_bucket_public_access_block`](../resources/s3_bucket_public_access_block) for the per-setting Ceph version support.

## Example Usage

```terraform
# Look up the public access block configured for an existing bucket
data "radosgw_s3_bucket_public_access_block" "example" {
  bucket = "my-private-bucket"
}

output "bucket_public_access_block" {
  description = "Public access block settings for the bucket"
  value = {
    block_public_acls       = data.radosgw_s3_bucket_public_access_block.example.block_public_acls
    block_public_policy     = data.radosgw_s3_bucket_public_access_block.example.block_public_policy
    ignore_public_acls      = data.radosgw_s3_bucket_public_access_block.example.ignore_public_acls
    restrict_public_buckets = data.radosgw_s3_bucket_public_access_block.example.restrict_public_buckets
  }
}
```

## Argument Reference

The following arguments are supported:


* `bucket` - (Required) The name of the bucket.



## Attributes Reference

The following attributes are exported:

* `block_public_acls` - Whether RadosGW blocks public ACLs for this bucket.
* `block_public_policy` - Whether RadosGW blocks public bucket policies for this bucket.
* `ignore_public_acls` - Whether RadosGW ignores public ACLs for this bucket.
* `restrict_public_buckets` - Whether RadosGW restricts public bucket policies for this bucket.
* `bucket` - See Argument Reference above.
