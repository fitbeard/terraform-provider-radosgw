# radosgw_iam_account_users

Lists the IAM users within a RadosGW account (via the IAM `ListUsers` API), optionally filtered by path prefix and/or a name regular expression. Use with account (or `iam:ListUsers`-granted) credentials.

## Example Usage

```terraform
# All IAM users under the /engineering/ path in the account.
data "radosgw_iam_account_users" "engineering" {
  provider    = radosgw.account_root
  path_prefix = "/engineering/"
}

output "engineering_user_names" {
  value = data.radosgw_iam_account_users.engineering.names
}
```

## Argument Reference

The following arguments are supported:


* `name_regex` - (Optional) Only return users whose name matches this regular expression (applied client-side).
* `path_prefix` - (Optional) Only return users whose path starts with this prefix (e.g. `/engineering/`).



## Attributes Reference

The following attributes are exported:

* `arns` - Set of matching user ARNs.
* `id` - Data source identifier.
* `names` - Set of matching user names.
* `name_regex` - See Argument Reference above.
* `path_prefix` - See Argument Reference above.
