# radosgw_iam_account

Retrieves information about an existing RadosGW account.

~> **Note:** Accounts require Ceph Squid (19.x) or later. On Ceph 20.2.1 the account read admin operation is broken by a capability-name bug; use 20.2.2 or later.

## Example Usage

```terraform
# Look up an existing RadosGW account by its account ID
data "radosgw_iam_account" "example" {
  account_id = "RGW00000000000000001"
}

output "account_name" {
  value = data.radosgw_iam_account.example.name
}

output "account_max_buckets" {
  value = data.radosgw_iam_account.example.max_buckets
}
```

## Argument Reference

The following arguments are supported:


* `account_id` - (Required) The account ID to look up.



## Attributes Reference

The following attributes are exported:

* `email` - The email address associated with the account.
* `id` - The account ID. Same value as `account_id`.
* `max_access_keys` - The maximum number of access keys the account can own (-1 for unlimited).
* `max_buckets` - The maximum number of buckets the account can own (-1 for unlimited).
* `max_groups` - The maximum number of groups the account can own (-1 for unlimited).
* `max_roles` - The maximum number of roles the account can own (-1 for unlimited).
* `max_users` - The maximum number of users the account can own (-1 for unlimited).
* `name` - The account name.
* `tenant` - The tenant under which the account exists.
* `account_id` - See Argument Reference above.
