# radosgw_caller_identity

Use this data source to get information about the identity that the provider's credentials resolve to, as reported by the STS `GetCallerIdentity` API. This is the RadosGW equivalent of `aws_caller_identity`.

The returned values depend on the kind of caller:

| Caller | `account_id` | `arn` | `user_id` |
|--------|--------------|-------|-----------|
| Plain (non-account) user | *(empty)* | `arn:aws:iam:::user/<uid>` | the user's UID |
| Account root | account ID | `arn:aws:iam::<account>:root` | the account ID |
| Account member user | account ID | `arn:aws:iam::<account>:user/<name>` | a unique ID |

~> **Ceph version:** `GetCallerIdentity` requires **Ceph 21 (Umbrella)**. When the provider's `ceph_version` is set to an older release, this data source returns an error.

## Example Usage

```terraform
# Look up the identity the provider's credentials resolve to (requires Ceph 21, Umbrella).
data "radosgw_caller_identity" "current" {}

output "caller_arn" {
  value = data.radosgw_caller_identity.current.arn
}

output "caller_user_id" {
  value = data.radosgw_caller_identity.current.user_id
}

output "caller_account_id" {
  value = data.radosgw_caller_identity.current.account_id
}
```

## Attributes Reference

The following attributes are exported:

* `account_id` - The RadosGW account ID of the caller. Empty for a plain (non-account) user; the account ID for an account root or account member user.
* `arn` - The ARN associated with the credentials used to make the request (e.g. `arn:aws:iam:::user/admin`, `arn:aws:iam::<account>:root`, or `arn:aws:iam::<account>:user/<name>`).
* `id` - The account ID of the caller, mirroring `account_id` (for parity with `aws_caller_identity`, whose `id` is the account ID).
* `user_id` - The unique identifier of the calling entity: the user's UID for a plain user, the account ID for an account root, or a unique ID for an account member user.
