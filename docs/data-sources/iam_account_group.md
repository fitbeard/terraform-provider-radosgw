# radosgw_iam_account_group

Looks up an IAM group within a RadosGW account (IAM `GetGroup`), including its member users. Use with account (or `iam:GetGroup`-granted) credentials.

## Example Usage

```terraform
data "radosgw_iam_account_group" "engineering" {
  provider = radosgw.account_root
  name     = "engineering"
}

output "engineering_members" {
  value = data.radosgw_iam_account_group.engineering.users
}
```

## Argument Reference

The following arguments are supported:


* `name` - (Required) The name of the IAM group to look up.



## Attributes Reference

The following attributes are exported:

* `arn` - The group's ARN.
* `path` - The group's IAM path.
* `unique_id` - The group's stable unique identifier.
* `users` - The names of the users that are members of the group.
* `name` - See Argument Reference above.
