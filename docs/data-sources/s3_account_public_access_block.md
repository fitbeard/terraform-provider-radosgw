# radosgw_s3_account_public_access_block

Reads the account-wide S3 Public Access Block configuration of a RadosGW account, via the S3 Control `GetPublicAccessBlock` API.

~> **Ceph version:** account-wide Public Access Block is **Ceph 21 (Umbrella) only**. Reading it when the provider's `ceph_version` targets an older release returns an error.

~> **Note:** When the account has no public-access-block configuration, all four settings are reported as `false` — the effective state, in which nothing is blocked.

## Example Usage

```terraform
# Look up the account-wide public access block for a RadosGW account.
# The provider must authenticate as the account's root user.
data "radosgw_s3_account_public_access_block" "example" {
  account_id = "RGW12345678901234567"
}

output "account_public_access_block" {
  description = "Account-wide public access block settings"
  value = {
    block_public_acls       = data.radosgw_s3_account_public_access_block.example.block_public_acls
    block_public_policy     = data.radosgw_s3_account_public_access_block.example.block_public_policy
    ignore_public_acls      = data.radosgw_s3_account_public_access_block.example.ignore_public_acls
    restrict_public_buckets = data.radosgw_s3_account_public_access_block.example.restrict_public_buckets
  }
}
```

## Argument Reference

The following arguments are supported:


* `account_id` - (Required) The ID of the RadosGW account.



## Attributes Reference

The following attributes are exported:

* `block_public_acls` - Whether RadosGW blocks public ACLs for buckets in this account.
* `block_public_policy` - Whether RadosGW blocks public bucket policies for buckets in this account.
* `ignore_public_acls` - Whether RadosGW ignores public ACLs for buckets in this account.
* `restrict_public_buckets` - Whether RadosGW restricts public bucket policies for buckets in this account.
* `account_id` - See Argument Reference above.
